# ADR-049: Gateway JWTs Use RS256 With KMS Rotation (Supersedes ADR-031)

- **Status:** Active (Supersedes ADR-031)
- **Date:** 2026-10-11
- **Deciders:** Vikram Desai, Arjun Mehta, Meera Patel
- **Decision ID:** DEC-033
- **Ticket Ref:** LIN-418
- **Supersedes:** DEC-030 (ADR-031)

## Context
Incident INC-81 on 2026-10-08 showed that the shared HS256 secret used by every auth-gateway pod could leak through ordinary logging. Anyone holding it could mint valid tokens, and rotating it required a full redeploy and a global logout.

## Decision
Sign gateway JWTs with RS256. Each pod holds its own private key, issued and rotated every 24 hours through KMS. Verifiers fetch public keys from a JWKS endpoint. The shared HS256 secret is removed from the config map (PR-1203).

## Consequences
- A leaked key affects one pod for at most 24 hours.
- Rotation no longer needs a redeploy or a global logout.
- Token verification adds a cached JWKS lookup.
